# AnyGoal v0.1.0b2

AnyGoal v0.1.0b2 improves artifact acquisition and checkpoint resolution for
the public beta benchmark API.

This release supports Python 3.10 and 3.11.

## Highlights

- Download registered external datasets and official LeWM checkpoints through
  the `anygoal artifacts download` CLI.
- Resume cached downloads and decompress Zstandard-compressed datasets into
  their configured data directory.
- Resolve default planning and rollout checkpoints consistently from the shared
  artifact catalog while preserving explicit checkpoint and model-config
  overrides.
- Add packaged LeWM model metadata and validation for evaluation configs and
  checkpoint compatibility.
- Improve CLI dependency guidance when optional evaluation packages are not
  installed.

## Install

```bash
uv venv --python 3.10
source .venv/bin/activate
uv pip install "anygoal[eval]==0.1.0b2"
```

Verify the installation without downloading datasets or checkpoints:

```bash
anygoal --version
anygoal list datasets
python -c 'import anygoal; print(anygoal.__version__)'
```

## Beta notes

- APIs and configuration schemas may evolve based on researcher feedback.
- External datasets and official checkpoints retain their original licenses and
  are downloaded from their original publishers.
- GPU-backed evaluation requires a compatible PyTorch build, accelerator
  driver, upstream model source, and model checkpoint.

Feedback, bug reports, and feature requests are welcome through GitHub Issues.
