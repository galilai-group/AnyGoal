# AnyGoal v0.1.0b1

AnyGoal v0.1.0b1 is the installable compositional generalization benchmark API for evaluating world models.

## Highlights

- Public Python API for collection, training, planning, and rollout evaluation.
- `anygoal` CLI for registry discovery, configuration, artifact management,
  dataset validation, collection, training, and evaluation.
- Registries and packaged runtime configurations for the supported datasets,
  environments, models, and visualizers.
- Clean wheel and sdist installation validated on Python 3.10 and 3.11.
- Apache-2.0 licensing for AnyGoal-authored source and AnyGoal-generated
  artifacts, with separate third-party attribution.

## Install

```bash
uv venv --python 3.10
source .venv/bin/activate
uv pip install anygoal==0.1.0b1
```

Verify the installation without downloading datasets or checkpoints:

```bash
anygoal --version
anygoal list datasets
python -c 'import anygoal; print(anygoal.__version__)'
```

## Beta notes

- APIs and configuration schemas may evolve based on researcher feedback.
- GPU-backed training and evaluation require a compatible PyTorch build,
  accelerator driver, upstream model source, and model checkpoint.
- Third-party model repositories and their artifacts are not included in the
  AnyGoal wheel and retain their original license and citation requirements.
- The InsertPeg dataset is derived from the Apache-2.0 RL Unplugged DM Control
  Suite dataset. See `docs/THIRD_PARTY_NOTICES.md` for attribution.

Feedback, bug reports, and feature requests are welcome through GitHub Issues.
