# AnyGoal v0.1.0

AnyGoal v0.1.0 is the first non-prerelease package version of the AnyGoal
benchmark.

This release supports Python 3.10 and 3.11.

## Highlights

- Use the configured training datasets to compute normalization statistics for
  planning and rollout evaluation.
- Add explicit normalization-statistics datasets to the packaged LeWM,
  Sensorimotor, PreJEPA, DriftWorld, and IRASim planning configurations.
- Preserve the validated dependency pins, public Python API, artifact catalog,
  and CLI workflows from the beta releases.

## Install

```bash
uv venv --python 3.10
source .venv/bin/activate
uv pip install "anygoal[eval]==0.1.0"
```

Verify the installation without downloading datasets or checkpoints:

```bash
anygoal --version
anygoal list datasets
python -c 'import anygoal; print(anygoal.__version__)'
```

External datasets and official checkpoints retain their original licenses and
are downloaded from their original publishers. GPU-backed evaluation requires
a compatible PyTorch build, accelerator driver, upstream model source, and
model checkpoint.

Feedback, bug reports, and feature requests are welcome through GitHub Issues.
